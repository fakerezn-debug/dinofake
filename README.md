# Season Dino Runner

Aplikasi game mandiri yang dapat dijalankan tanpa Replit.

## Menjalankan

1. Unduh season-dino-runner-standalone.zip dari repository ini.
2. Ekstrak ZIP dan buka folder standalone-season-dino-runner di Visual Studio Code.
3. Jalankan npm install.
4. Jalankan npm run dev.
5. Buka http://localhost:5173 di browser.

Versi ini tidak menggunakan konfigurasi atau layanan Replit.
